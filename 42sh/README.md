# 42sh: Recreating bash

### My work:
As we were in groups of 4 to implement bash, I did not do everything. However, I hovered around most parts.
Firstly, I was in charge of the lexer (i.e constructing all the most most basic tokens from the input characters to give it to the parser).
Then, I actively participated in the execution part, I then had an overview of all the project (except the parser which was a black-box to me).
